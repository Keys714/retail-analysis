# 简历项目描述

> 使用原则：简历上只写你能讲清楚的内容。面试前至少通读 `README.md`、`reports/analysis_report.md` 和 `src/` 下的代码，能解释每个数字的来源与口径。

## 版本 A：数据分析 / 商业分析岗（推荐）

**电商零售用户分析与复购预测** | 个人项目 | 2026.10

技术栈：Python、pandas、NumPy、scikit-learn、Matplotlib、Streamlit、Git、Parquet

- 清洗 54.2 万条英国零售交易数据：去重 5,268 行，拆分正常销售、取消退货与库存调整，剔除 POST、DOT、M、AMAZONFEE 等非商品编码，构建 52.3 万条有效商品销售明细和 Parquet 数据层。
- 完成销售趋势、市场/商品集中度、复购率与 RFM 分层分析：商品销售额 1,024.8 万、订单 19,773 笔、客户 4,334 人；英国贡献 85.14% 销售额，Top 10% 客户贡献 61.37%，Top 20% 商品贡献 78.83%，复购率 65.27%。
- 基于 RFM 与行为特征构建复购预测模型（23 个特征，180 天观察窗口 + 90 天标签窗口），采用时间外验证，并用训练集 5 折交叉验证选型；逻辑回归测试 AUC 0.728（CV 0.756），Top 10% 高风险客户精确率 96.0%，Lift 1.56，优于近期购买规则基线（AUC 0.658）。
- 使用 Matplotlib 输出 5 张分析图表与完整报告，Streamlit 搭建支持日期/国家筛选的交互看板，展示 KPI、月度趋势、国家分布、RFM 分层与高价值低复购概率客户名单。

## 版本 B：算法 / 数据科学岗

**电商零售复购预测** | 个人项目 | 2026.10

技术栈：Python、pandas、scikit-learn、NumPy、Matplotlib、Streamlit、Git

- 基于 52.3 万条有效交易构建 23 维客户行为特征，覆盖 R/F/M、购买间隔、近 90 天活跃度、取消行为与客户生命周期；以 180 天观察窗口预测未来 90 天复购。
- 采用时间外验证：2011-06-09 快照训练、2011-09-09 快照测试；模型选择仅使用训练集 5 折交叉验证，测试集用于最终评估，避免信息泄漏。
- 逻辑回归在测试集上 AUC 0.728、PR-AUC 0.824；Top 10% 人群精确率 96.0%、Lift 1.56，优于梯度提升树（AUC 0.701）和近期购买规则（AUC 0.658）。
- 通过置换重要性识别购买天数、购买次数、活跃跨度、近 90 天频次为核心特征；输出高价值低复购概率客户名单，支持运营定向召回。

## 版本 C：两行精简版

电商零售用户分析与复购预测（Python/pandas/scikit-learn/Streamlit）：清洗 54.2 万条交易数据，完成销售、RFM 与复购分析；识别英国市场贡献 85.14%、Top 10% 客户贡献 61.37% 销售额；构建时间外验证的复购模型（AUC 0.728，Top 10% 精确率 96.0%），并交付交互看板。

## 面试前必须能解释的三件事

1. **为什么这样清洗**：取消发票、库存调整、非商品编码分别是什么，为什么要分开。
2. **为什么这样验证**：为什么用时间外验证，为什么用交叉验证选模型，怎样避免数据泄漏。
3. **为什么 AUC 0.728 有用**：它不算高，但 Top 10% 的精确率 96.0%、Lift 1.56，说明模型适合做“优先触达排序”，而不是替代人工判断。

## 不要写的内容

- 不要写“提升销售额 X%”——本项目没有做因果实验或线上 A/B 测试。
- 不要写“上线/部署到生产环境”——看板是本地 Streamlit 应用。
- 不要写“PB 级数据/实时计算”——数据规模是 54 万行，批次分析。
- 不要把 96.0% 写成“模型准确率 96%”——它是 Top 10% 人群的精确率，测试集基准复购率本身就有 61.51%。
